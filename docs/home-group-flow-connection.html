홈에서 그룹 생성·참여 플로우를 이렇게 연결했다

그룹 생성/참여 화면 자체는 온보딩 플로우에 이미 있었다. 이번 작업은 홈 화면의 "+" 메뉴를 그 화면들에 연결하고, 요청이 진행 중인 동안 화면을 벗어나 데이터가 어긋나는 상황을 막은 기록이다.

HomeView→ GroupNameView / InviteCodeInputView→ 홈 목록 갱신

01 연결된 플로우

홈의 + 버튼 메뉴 두 항목이 HomeViewModel.Destination(@CasePathable enum)을 통해 각 화면으로 push된다. 완료 지점은 두 갈래인데, 생성은 초대코드 공유 화면을 한 번 거치고, 참여는 확인 화면 없이 곧바로 홈으로 돌아온다.

이번 작업에서 연결한 경로

02 참여 완료 처리 정리

참여 확인 화면(JoinConfirmView/JoinConfirmViewModel)을 제거했다. InviteCodeInputViewModel.joinTapped()가 성공하면 곧바로 onFinish()를 호출해 홈으로 pop되고, 완료 안내는 RootView가 상단 토스트("그룹에 합류했어요!")로 대신한다.

03 요청 진행 중 화면 이탈 방지

그룹 생성·참여 요청이 진행되는 동안 뒤로가기 버튼과 인터랙티브 스와이프 백 제스처를 모두 막았다. 화면 전체를 덮는 로딩 오버레이가 함께 떠서 지금 요청 중임을 알린다.

대상적용
GroupNameViewmomogoLoadingOverlay(isPresented: viewModel.isLoading) + navigationBarBackButtonHidden(viewModel.isLoading)
InviteCodeInputView동일하게 적용
