03 파일별 책임

전부 Projects/Data/Sources/Networking/ 아래에 있다.

파일역할
NetworkConfiguration.swiftInfo.plist의 API_BASE_URL을 읽어 baseURL: URL을 만든다. 키가 없으면 즉시 크래시 — 설정 누락을 배포 전에 드러내기 위함.
NetworkTargetType.swiftMoya TargetType 확장 프로토콜. baseURL / headers / validationType 기본값을 주고, requiresAuthorization 플래그를 새로 선언한다. 실제 API enum은 path/method/task만 채우면 된다.
AccessTokenStore.swift현재 액세스 토큰을 들고 있는 락 기반 저장소. 로그인 기능이 아직 없어 지금은 항상 비어 있다 — 나중에 로그인 플로우가 update(_:)만 호출하면 됨.
AuthorizationPlugin.swiftMoya PluginType. 요청 직전 requiresAuthorization과 토큰 유무를 보고 Authorization 헤더를 붙일지 말지 결정한다.
NetworkClient.swiftData가 network에 요구하는 포트. raw Data 요청 클로저 + 제네릭 디코딩 편의 메서드 requestDecodable(_:).
NetworkClient+Live.swiftMoyaProvider 실제 구성(플러그인 장착), 상태 코드 → NetworkError 매핑, liveValue/testValue/previewValue 제공.
NetworkError.swiftRepository가 받게 되는 에러 타입. 아래 05번 표 참고.

04 인증 — 토큰은 이렇게 자동으로 붙는다

API 정의 쪽에서 아무것도 안 하면 인증이 필요한 것으로 간주한다. 로그인·회원가입처럼 인증이 필요 없는 API만 requiresAuthorization을 false로 오버라이드하면 된다.

로그인이 필요 없는 API 예시
enum AuthAPI: NetworkTargetType {
    case login(id: String, password: String)

    var requiresAuthorization: Bool { false }

    var path: String { "/v1/auth/login" }
    var method: Moya.Method { .post }
    var task: Moya.Task {
        switch self {
        case let .login(id, password):
            return .requestJSONEncodable(["id": id, "password": password])
        }
    }
}

05 에러는 이렇게 좁혀진다

NetworkClient+Live.swift의 mapToData(_:)가 응답을 받자마자 상태 코드를 확인해서, Repository가 switch로 바로 분기할 수 있는 형태로 좁혀준다.

상황NetworkError의미
200–299(에러 아님)응답 Data 그대로 반환, 이후 requestDecodable이 디코딩 진행
401.unauthorized인증 실패 / 토큰 만료
그 외 상태 코드.serverError(statusCode:)서버 측 오류 응답
디코딩 단계.decodingFailed(Error)응답 JSON과 모델 타입 불일치
요청 자체 실패.underlying(Error)네트워크 단절 등 Moya/URLSession 레벨 오류

06 새 API를 추가하는 법

Data 안에 API enum 하나, Repository 구현체 하나만 추가하면 된다. baseURL·인증·에러 처리는 신경 쓸 필요 없다.

  1. API 정의NetworkTargetType을 채택하는 enum을 만들고 path/method/task만 정의한다.
  2. Repository에서 호출@Dependency(\.networkClient)로 주입받아 requestDecodable(_:)로 바로 디코딩된 모델을 받는다.
  3. 에러는 그대로 위임Repository는 NetworkError를 그대로 던지거나 도메인 에러로 한 번 감싸서 UseCase에 전달한다.
01 · API 정의
enum HomeAPI {
    case fetchMeals(date: String)
}

extension HomeAPI: NetworkTargetType {
    var path: String {
        switch self {
        case .fetchMeals:
            return "/v1/meals"
        }
    }

    var method: Moya.Method { .get }

    var task: Moya.Task {
        switch self {
        case let .fetchMeals(date):
            return .requestParameters(
                parameters: ["date": date],
                encoding: URLEncoding.queryString
            )
        }
    }
}
02 · Repository에서 호출
struct MealRepository {
    @Dependency(\.networkClient) var networkClient

    func fetchMeals(date: String) async throws -> [MealDTO] {
        try await networkClient.requestDecodable(HomeAPI.fetchMeals(date: date))
    }
}
