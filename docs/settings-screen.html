01 추가된 API

Domain(UseCase·Repository interface)부터 Data(Repository liveValue)까지 새로 뚫은 엔드포인트 2개.

APIUseCase호출 경로비고
PATCH /user UpdateNicknameUseCase userRepository.updateNickname → userDataSource.update 요청 UpdateUserRequestDTO(nickname:), 응답 UpdateUserResponseDTO(userId, nickname)
DELETE /user DeleteAccountUseCase userRepository.deleteAccount → userDataSource.delete 성공 시 accessToken·refreshToken·게스트 UUID까지 로컬에서 함께 정리
